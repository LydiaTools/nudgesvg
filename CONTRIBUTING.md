# Contributing

Please describe the task and expected result, and include a small SVG you have permission to share. Do not upload private customer artwork or credentials.

Useful bug reports identify the browser/version, input file, exact operation and exported result. Expected-vs-observed source fragments are especially helpful. A reduced synthetic fixture is preferable to a large document.

Run `npm test` and the browser checks in the README. Preserve the source-range invariant; do not silently flatten unsupported text or strip unsupported content to make an import pass. Update both language entry points when changing user-facing behaviour.
