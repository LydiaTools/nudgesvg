# Third-party software and inspiration

Application code, logo and practice drawing are original MIT-licensed LydiaTools work. No Anatomy, SVG-Edit or Method Draw source/assets are vendored.

- Development: [Playwright](https://github.com/microsoft/playwright), Apache-2.0, installed separately through npm. Browser binaries retain their own licenses and are not included in the release ZIP.
- Example generation: [Pele 1.7.0](https://github.com/obsidianmd/pele), MIT, is a development dependency. The garden planning text is original LydiaTools synthetic input; the committed SVG contains Pele-generated styling. Its full distributed notice is preserved in [examples/pele/PELE-LICENSE.txt](examples/pele/PELE-LICENSE.txt). The renderer is not included in the four-file editor runtime. This is an independently tested interoperability example, without an upstream endorsement.
- Research: [Anatomy #124](https://github.com/wheresryan22/anatomy/issues/124), a public editing-friction discussion with a contributor's own figure-specific implementation. The issue is a problem source, not an endorsement or a copied implementation.
- Existing drawing tools referenced for scope: [SVG-Edit](https://github.com/SVG-Edit/svgedit), [Method Draw](https://github.com/methodofaction/Method-Draw).

Screenshots show the actual NudgeSVG interface with original practice files or the identified Pele rendering of original garden input. They are not AI-generated interface mockups.
